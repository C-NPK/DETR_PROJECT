Project Overview

What is DETR?

DETR (Detection Transformer) is a novel approach to object detection that treats object detection as a direct set prediction problem. Unlike traditional detection methods, DETR eliminates the need for hand-designed components like anchor generation and non-maximum suppression.

About This Project

This project implements DETR-based object detection using the SHHS dataset. It includes multiple training configurations, early stopping mechanisms, and confidence dropout techniques for improved model performance.

Key Highlights

  • 🎯 State-of-the-art transformer-based object detection
  • 🔧 Multiple training configurations and strategies
  • 📊 Built-in validation and performance tracking
  • 🛡️ Early stopping and regularization techniques
  • 💾 Automatic model checkpointing
  • 📈 Training and validation loss visualization

Features

Transformer Architecture

Leverages the power of transformer networks for accurate object detection without traditional anchor-based methods.

Multiple Training Modes

Includes basic training (train0.py) and advanced training with early stopping and confidence dropout (train2.py).

Performance Monitoring

Comprehensive validation tracking, loss monitoring, and automatic best model saving based on validation performance.

SHHS Dataset Support

Custom dataset loader specifically designed for the SHHS (Shanghai Head Human Surveillance) dataset format.

Early Stopping

Intelligent early stopping mechanism to prevent overfitting and optimize training efficiency.

Model Checkpointing

Automatic saving of best models and training metrics for reproducibility and model analysis.

Installation & Setup

Prerequisites

Before getting started, ensure you have the following installed:

  • Python 3.8 or higher
  • CUDA-compatible GPU (recommended for training)
  • Git for version control

Installation Steps

1. Clone the Repository

# Clone the project
git clone https://github.com/C-NPK/DETR_PROJECT.git
cd DETR_PROJECT

2. Install Dependencies

# Install required packages
pip install torch torchvision
pip install transformers
pip install pillow numpy
pip install json time collections

3. Prepare Your Dataset

# Organize your dataset in the following structure:
dataset/
├── train/
│   ├── Images/
│   └── Annotations/
├── val/
│   ├── Images/
│   └── Annotations/
└── test/
    ├── Images/
    └── Annotations/

Usage Guide

Training Configuration

Before training, update the dataset paths in your training script:

Update Dataset Paths

# Update these paths in your training script
train_images_path = "path/to/your/dataset/train/Images"
train_json_path = "path/to/your/dataset/train/Annotations"
val_images_path = "path/to/your/dataset/val/Images"
val_json_path = "path/to/your/dataset/val/Annotations"

Training Options

Basic Training

Use train0.py for standard DETR training:

python train0.py
  • Standard training loop
  • Best model saving based on validation loss
  • Training and validation loss tracking

Advanced Training

Use train2_earlystop_confdropout.py for enhanced training:

python train2_earlystop_confdropout.py
  • Early stopping mechanism
  • Confidence dropout regularization
  • Patience-based training termination

Model Information

Base Model

This project uses the pre-trained DETR model from Facebook Research:

  • Model: facebook/detr-resnet-50
  • Backbone: ResNet-50
  • Framework: PyTorch via Hugging Face Transformers

Training Outputs

Model Files

  • best_model0.pth - Best model from basic training
  • last_model0.pth - Final model from basic training
  • best_model2.pth - Best model from advanced training
  • last_model2.pth - Final model from advanced training

Training Metrics

  • model0_training_losses.npy - Training loss history
  • model0_validation_losses.npy - Validation loss history
  • model2_training_losses.npy - Advanced training losses
  • model2_validation_losses.npy - Advanced validation losses
